Test Status Definitions

Not Run: Test case has been created but not executed.

Pass: All required expected results were met.

Fail: One or more expected results were not met.

Blocked: Testing could not be completed due to an external issue, missing requirement, or unavailable feature.

Retest Required: The test must be executed again after a potential fix or software update.

Testing Procedure

For each test case:

1. Review the test objective and prerequisites.
2. Record the current game version.
3. Execute the documented test steps.
4. Compare actual results against expected results.
5. Capture screenshots or video when applicable.
6. Record the execution date and test status.
7. Link any relevant bug reports.
8. Retest failed scenarios after updates or potential fixes.
9. Update this tracker with verified results.

---

QA Documentation Standards

All testing results should reflect actual gameplay observations.

Previously observed bugs do not automatically count as failed test executions. Each structured test must be executed and evaluated independently.

Suspected causes should be distinguished from confirmed behavior.

Test documentation will continue to expand as additional features, bugs, and regression scenarios are investigated.
