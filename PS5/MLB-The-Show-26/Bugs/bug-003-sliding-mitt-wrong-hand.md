# Bug #003 - Runner Slides Back to First Base Using Wrong Hand While Wearing Sliding Mitt

## Game
MLB The Show 26

## Platform
PlayStation 5

## Mode
Ranked Co-op

## Category
Animation / Equipment

## Severity
Low

## Priority
Low

## Description
A baserunner wearing a sliding mitt can dive back to first base using the opposite hand instead of the hand protected by the sliding mitt.

This creates a visual inconsistency between the player's equipped gear and the sliding animation.

## Steps to Reproduce
1. Launch MLB The Show 26.
2. Enter a Ranked Co-op game.
3. Get a runner on first base who is wearing a sliding mitt.
4. Allow the opposing pitcher to attempt a pickoff throw to first base.
5. Observe which hand the runner uses while diving back to the base.

## Expected Result
The runner should use the hand protected by the sliding mitt when reaching back toward first base.

## Actual Result
The runner reaches toward the base using the opposite hand while the sliding mitt remains equipped on the other hand.

## Reproduction Rate
Observed multiple times.

Additional testing is needed to determine the exact reproduction percentage.

## Notes
This appears to be a cosmetic animation or equipment synchronization issue and does not appear to affect gameplay.

## Evidence
Screenshot or video showing the sliding mitt on one hand while the opposite hand is used during the pickoff animation.
