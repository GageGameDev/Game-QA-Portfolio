# Bug #001 - Map Marker Does Not Match Actual Item Location

## Game
Far Cry 3

## Platform
Needs PS5

## Category
Map / Navigation / UI

## Severity
Low

## Priority
Medium

## Description
Some items shown on the in-game map are not located exactly where their map marker indicates.

When traveling to the marked location, the player may reach the point shown on the map but find that the item is actually farther away and requires additional movement or searching.

## Steps to Reproduce
1. Launch Far Cry 3.
2. Open the in-game map.
3. Select or travel toward a marked item location.
4. Reach the location indicated by the map marker.
5. Search the immediate area for the item.
6. Continue traveling beyond the marked location.
7. Observe whether the item is located farther away than the map indicates.

## Expected Result
The item should be located at or very near the position shown by its map marker.

## Actual Result
The player reaches the map marker, but the item is not located at that position.

The player must travel farther beyond the indicated location before finding the item.

## Reproduction Rate
Observed multiple times.

Exact reproduction rate needs additional testing.

## Notes
The issue can make navigation confusing because the map suggests the player has reached the correct location even though the item is still farther away.

Additional testing should record:
- The specific item type
- The exact map location
- Approximate distance between the marker and the actual item
- Whether the issue occurs consistently at the same location

## Evidence
A screenshot or video showing the map marker and the actual item location would help demonstrate the distance between the two positions.
