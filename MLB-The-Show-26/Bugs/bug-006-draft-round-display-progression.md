# Bug #006 - Draft Round Display Progression Becomes Inconsistent

## Game
MLB The Show 26

## Platform
PlayStation 5 - Retest Recommended

## Mode
Draft / Draft Interface

## Category
UI / Draft Progression

## Severity
Medium

## Priority
Medium

## Description
The draft interface can display inconsistent round information as draft selections progress.

During the observed occurrence, the interface displayed first-round and second-round selections before progressing in a way that caused the round information to become inconsistent when moving into the third round.

## Steps to Reproduce
1. Launch MLB The Show 26.
2. Enter the applicable draft mode.
3. Begin or view the draft process.
4. Progress through the first round.
5. Continue through the second round.
6. Observe the displayed round information as the draft progresses into the third round.
7. Compare the displayed round with the actual draft selection order.

## Expected Result
The draft interface should display the correct round for every selection and update sequentially as the draft progresses.

## Actual Result
The displayed draft-round information becomes inconsistent with the actual progression of the draft.

## Reproduction Rate
Needs additional testing.

## Notes
The original issue involved the interface showing first-round and second-round selections before becoming inconsistent as the draft moved to the third round.

Additional testing should record the exact pick numbers and displayed round labels when the issue occurs again.

## Evidence
A screenshot or video showing the draft pick number and incorrect round label would provide the strongest evidence.
